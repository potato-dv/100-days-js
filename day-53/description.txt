Objective: Hide storage details behind a small data-access API.
Challenge: Build create, findAll, findById, update, and remove functions for users.json.
Requirements
    • Generate unique ids.
    • Return null for a missing record.
    • Preserve unrelated fields during patch-style updates.
Example: await repository.update("u2", {active: false}) -> updated user

  return { findAll, findById, create, update, remove };
